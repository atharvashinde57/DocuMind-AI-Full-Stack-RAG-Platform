-------------------------------------------------------------------------------
PART 1: WHAT IS DOCUMIND AI? (IN SIMPLE WORDS)
-------------------------------------------------------------------------------
DocuMind AI is an intelligent digital assistant for your documents (PDFs, Word 
files, text files). 

Instead of manually reading through hundreds of pages to find a specific policy,
financial figure, or clause, you simply upload your file and ask questions in 
plain English. DocuMind AI reads the file, finds the exact relevant paragraph 
in less than a second, and gives you a direct answer with page citations.


-------------------------------------------------------------------------------
PART 2: TECHNOLOGY STACK EXPLAINED IN LAYMAN TERMS
-------------------------------------------------------------------------------

1. REACT 18 + TYPESCRIPT (The Visual Front Screen)
   - What it does: This is everything you see and click on your screen—the buttons, 
     colors, layout, upload boxes, and chat windows.
   - Layman explanation: Think of it like the dashboard of a luxury car. It gives 
     you clear meters, buttons, and a steering wheel so you can control the vehicle 
     without needing to touch the engine.

2. TAILWIND CSS (The Styling & Beautifier)
   - What it does: Makes the website look modern, polished, dark-themed, and responsive 
     with glassmorphic panels and smooth animations.
   - Layman explanation: Like the interior leather seating, sleek paint job, and 
     glowing dashboard lights of a car.

3. PYTHON 3.11 & FASTAPI (The AI Brain / Backend Engine)
   - What it does: Handles all heavy artificial intelligence operations—reading 
     uploaded files, breaking text into smart chunks, searching vector database, 
     and generating accurate answers.
   - Layman explanation: This is the high-performance engine under the hood. When 
     you ask a question, this engine does the math and text processing in milliseconds.

4. LANGCHAIN (The Smart Librarian / Orchestrator)
   - What it does: Coordinates document loaders, text splitters, AI prompt templates, 
     and language models into a smooth flow.
   - Layman explanation: Think of LangChain as a super-smart librarian. When you ask 
     a question, the librarian knows exactly which shelf to check, pulls out the right 
     book, opens to the right page, and hands it to the assistant.

5. FAISS by Meta/Facebook (The Ultra-Fast Vector Search Engine)
   - What it does: Converts document text into mathematical coordinates (vectors) 
     and searches millions of text chunks in sub-milliseconds.
   - Layman explanation: Imagine a giant digital filing cabinet where similar topics 
     are grouped on the exact same shelf. FAISS instantly grabs the right folder 
     without having to read through every file manually.

6. SENTENCE-TRANSFORMERS (Language Meaning Model)
   - What it does: Converts human words into meaning vectors so the computer understands 
     concepts rather than just matching exact letters.
   - Layman explanation: If you search for "car", it understands you also mean "vehicle" 
     or "automobile", even if the word "car" is not explicitly written on the page.

7. OPENAI API / GPT-4o / LOCAL AI (The Answer Writer)
   - What it does: Writes clean, polite, easy-to-read answers based strictly on the 
     retrieved document context.
   - Layman explanation: The smart assistant who takes the relevant book snippet found 
     by the librarian and writes a neat summary sentence for you.

8. JAVA 17 & SPRING BOOT 3 (The Security Guard & Gateway)
   - What it does: Manages user registration, login security (passwords & tokens), 
     and directs network traffic safely between users and the AI engine.
   - Layman explanation: The security guard at the building entrance. It checks your 
     ID card before letting you access your private documents.

9. DOCKER & RENDER (The Delivery Box & Hosting Cloud)
   - What it does: Packages the entire web app into a single neat container so it 
     runs reliably anywhere on the internet.
   - Layman explanation: Like packing an entire fully-furnished office into a shipping 
     container and plugging it into the cloud so anyone worldwide can use it.

PART 3: EXPLANATION OF EVERY PAGE & ITS FEATURES
-------------------------------------------------------------------------------

PAGE 1: LANDING PAGE (Home Screen)
- What it is: The welcome page displayed when you first open the website.
- Key Features:
  1. Welcome Banner & Subtitle: Clear explanation of enterprise document intelligence.
  2. "How RAG Works" Diagram: A 4-step visual flow showing Document Upload -> 
     FAISS Vector Search -> Context Retrieval -> Grounded Answer.
  3. Action Buttons: "Upload Documents & Chat" button to jump into the app, and 
     "OpenAPI FastAPI Docs" button for technical users.

PAGE 2: DOCUMENTS KNOWLEDGE BASE (Document Upload & Manager)
- What it is: The digital filing cabinet where you upload and manage your files.
- Key Features:
  1. Drag-and-Drop Uploader: Simply drag your PDF, Word (.docx), or Text (.txt/.md) 
     file into the box to upload.
  2. Live Processing Indicator: Shows progress while your document is being parsed 
     and split into vector chunks.
  3. Document Registry Table: Lists all your indexed documents showing file name, 
     file type badge, upload timestamp, file size, and total chunk count.
  4. Delete Document Button: Lets you delete any document and erase its search vectors 
     with one click.

PAGE 3: RAG ASSISTANT (Interactive Chat Screen)
- What it is: The main conversation screen where you ask questions about your files.
- Key Features:
  1. Prompt Mode Selector: Toggle between 3 smart assistant modes:
     - Question Answering: Direct, accurate answers to your questions.
     - Executive Summary: A quick bullet-point summary of the document.
     - Document Analysis: In-depth structural audit of topics and insights.
  2. Grounded Responses: Answers are strictly based on your uploaded documents 
     (no guessing or hallucinations).
  3. Confidence Score Badge: Shows how strongly the answer matches your documents 
     (e.g., "94% Grounded").
  4. Clickable Source Citations: Displays source document name and page number. 
     Clicking it opens a drawer showing the raw paragraph snippet!

PAGE 4: RAG DEBUG INSPECTOR (AI Search Inspector)
- What it is: A diagnostic window showing how the AI searches your files behind the scenes.
- Key Features:
  1. Live Query Search Box: Type any query to test the vector search pipeline.
  2. Pipeline Telemetry Steps: Shows step 1 (embedding generation) -> step 2 (FAISS search) -> 
     step 3 (chunk filtering) -> step 4 (prompt assembly).
  3. Raw Vector Chunks List: View the exact retrieved text blocks with their raw 
     similarity distance scores.

PAGE 5: EVALUATION & BENCHMARKING DASHBOARD (System Metrics Dashboard)
- What it is: The performance control panel showing overall system accuracy and speed.
- Key Features:
  1. Avg Retrieval Score: Measures how relevant the found document parts are (e.g., 0.89 / 1.0).
  2. Avg Response Latency: Shows answer generation speed (e.g., 1.42 seconds).
  3. Grounded Responses Rate: Shows zero-hallucination accuracy percentage (e.g., 94.5%).
  4. Recent Query Benchmarks Table: Displays history log of questions, latency in ms, 
     and groundedness status.
